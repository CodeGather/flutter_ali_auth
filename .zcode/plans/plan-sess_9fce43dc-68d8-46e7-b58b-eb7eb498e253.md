## 动态参数配置页面 — 分组方案

### 页面结构
每组的标题栏使用 `ExpansionTile` 折叠面板，点击展开该组所有参数，标题栏显示组名和当前参数数量。

### 14 个分组

```
┌─────────────────────────────────────┐
│ [androidSk: text] [iosSk: text]     │  ← 顶部固定栏（不折叠）
│ [pageType: ▼] [isDebug: ⬜]         │
├─────────────────────────────────────┤
│ 一、状态栏 (5项)              ▶    │
│ 二、导航栏 (13项)             ▶    │
│ 三、Logo区 (8项)              ▶    │
│ 四、Slogan区 (6项)            ▶    │
│ 五、掩码栏 (5项)              ▶    │
│ 六、登录按钮 (12项)           ▶    │
│ 七、切换按钮 (5项)            ▶    │
│ 八、自定义控件 (2项)          ▶    │
│ 九、协议栏 (12项)             ▶    │
│ 十、弹窗设置 (8项)            ▶    │
│ 十一、全屏属性 (6项)          ▶    │
│ 十二、iOS弹窗 (9项)           ▶    │
│ 十三、二次隐私弹窗 (20+项)    ▶    │
│ 十四、Toast设置 (9项)         ▶    │
├─────────────────────────────────────┤
│   [  应用配置  ]  [  重置  ]        │  ← 底部固定按钮
└─────────────────────────────────────┘
```

### 每组内部布局
展开后每个参数一行，格式统一：
```
参数名  [ 输入框/开关/下拉 ]    ← 右侧带默认值提示
```

例如：
```
navColor     [ #026ED2 ________________ ]
navHidden    [ ⬜ ]
navText      [ 一键登录 _______________ ]
pageType     [ 全屏竖屏 ▼ ]
```

### 输入控件类型
- **颜色/文本/路径** → `TextField`，填入即生效
- **布尔值** → `Switch` 开关
- **数字** → `TextField` + `keyboardType: TextInputType.number`
- **枚举** → `DropdownButton` 下拉选择（显示中文标签）

### 实现方式
每个分组用独立的 build 方法，参数状态用 `Map<String, dynamic>` 统一管理，初始化时填充 `AliAuthModel` 构造器的默认值。
